# מרחב הלמידה המשפחתי

מרחב למידה משפחתי עבור Adar, Ron ו־Harel, למבחנים ולתרגולים במהלך השנה. האתר בעברית ומותאם לטלפון, עם חלוקה לפי ילד, מקצוע ומבחן.

## מבנה
- דף כניסה: אדר, רון והראל.
- דף מקצועות של Adar: אזרחות וספרות (מקום להמשך השנה).
- אזרחות ← הכנה למבחן אוקטובר 27 ← שמונה בחנים של 15 שאלות.
- באזרחות: הסבר אחרי כל תשובה במצב תרגול, או לאחר הגשה במצב מבחן.
- רון ← כיתה ח׳ ← אנגלית ← מבחן נובמבר 26. שלושה מבחנים בני 30 שאלות, עם טיוטה מקומית נפרדת לכל מבחן ובדיקה עצמית בעת הצורך.
- ערבוב תשובות ושאלות, בוחן מעורב, חזרה על טעויות ושמירת התקדמות בדפדפן המקומי.

## הפעלה
פותחים את `index.html` בדפדפן. אין התקנה, חשבון או שרת.
שאלות האזרחות משולבות בדף. שאלות האנגלית נמצאות ב־`data/english/november-26/exams.js`. שני המקצועות זמינים בהפעלה מקומית ללא חיבור לרשת.
`data/civics/october-27/questions.json` מכיל את מאגר השאלות בפורמט קריא לעריכה.

## בדיקה
`node verify.cjs` בודק את שלמות המאגר ואת התנהגות הניווט, הניקוד, מצבי התרגול ושמירת ההתקדמות. זו בדיקת קוד ללא בדיקה חזותית בדפדפן.

## מקור והיקף
השאלות נכתבו מתוך סיכום הכיתה ושלושה דפי מחברת שהועברו להכנת התרגול. אין כאן תמונות מקור, שמות תלמידים או פרטים אישיים. זהו תרגול משלים; המבחן בבית הספר עשוי לדרוש תשובות פתוחות ומנומקות.

## הרחבה למקצועות נוספים
הניווט מבוסס hash ולכן מתאים ל־GitHub Pages גם תחת שם מאגר. אפשר להוסיף דפי מקצוע ומאגרי שאלות נוספים. הכותרת ״הכנה למבחן אוקטובר 27״ נשמרה כפי שהתבקשה, ללא הנחת תאריך או שנה.

## פרסום ב־GitHub Pages
Settings → Pages → Deploy from a branch → main → / (root) → Save.

## סבב מתקדם
בחנים ה׳–ו׳ ברמה גבוהה ובחנים ז׳–ח׳ ברמה גבוהה מאוד. בכל בוחן 15 שאלות, מתוכן שלוש שאלות לחיזוק הביטחון. ערבוב השאלות בבחנים אלה מפזר אותן בתחילת הבוחן ובמהלכו. המסיחים מכוונים להבחנות בין מושגים קרובים ולהסקת מסקנות מהנתונים. הבחנים א׳–ד׳ וההתקדמות הקיימת נשמרים.

## משחק הכפל

המשחק זמין תחת הראל ← כיתה ג׳ ← חשבון והנדסה. קובצי האתר הבנויים נמצאים ב־`games/multiplication-arcade/` ונפרסים יחד עם מרחב הלמידה.

מקור: [practicing-multiplication-tables](https://github.com/nSharet/practicing-multiplication-tables), גרסה `cf50ff097734f500aed9ad296896031e49624804`. לבנייה מחדש, יש להחיל על גרסה זו את `tools/multiplication-arcade.patch` עם `git apply`, להריץ `npm install` ואז `npm run build -- --base=./` בתיקיית `multiplication-arcade`, ולהחליף את קובצי המשחק בתוכן של `dist`.
